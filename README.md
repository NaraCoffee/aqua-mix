# 반짝 수족관 — 주승재

`figma→html/css` 항목의 로컬 HTML/CSS 실습 결과입니다.

## 실행

`index.html`을 브라우저로 엽니다. `css/style.css`와 `img/hero.webp`를 함께 보관합니다.

## 참고한 수업자료 (C 드라이브의 testing, Project만 사용)

- `C:\testing\21` 및 `C:\Project\flex-plants`: 카드 flex, 가격 줄, grid 구역, footer
- `C:\testing\22\3`: sticky header, relative/absolute 태그, fixed TOP 버튼
- `C:\testing\19`: grid 선 번호로 열 배치
- `C:\testing\13`: background-image, background-size, background-position
- `C:\testing\13\img\dolphin.img`: 배너 이미지 원본. 같은 WEBP 바이트를 `img/hero.webp`로 복사
- `C:\testing\24\3\css\media.css`: media query의 flex 방향과 grid 열 변경

CSS는 reset·기본 → header → 배너 → 체험 프로그램 → 관람 구역 → footer·TOP → 모바일 순서입니다. 외부 예제, 라이브러리, 이미지는 추가하지 않았습니다. 예약 버튼은 HTML/CSS 배치 실습용이며 예약 처리는 구현하지 않습니다.

로컬 폴더에 원본 Figma 디자인 및 수족관 전용 HTML·hero.svg가 없어 원본 디자인과의 동일성은 확인하지 못했습니다. 배너는 로컬 수업 이미지로 구성했습니다.
